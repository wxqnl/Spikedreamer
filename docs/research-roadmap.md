# 从当前结果到可检验的论文贡献

当前判断：值得继续。Gated Memory 在 Walker 的完整 1M 训练中达到 925.96，相对旧 Stateful-T8 的 637.38 有较大提升，末十次评估均值也由 645.16 提升到 903.64。这个信号足以支持下一轮受控实验；是否形成论文，取决于收益能否复现、归因及扩展。

本页是研究建议，不是已批准的训练任务，也不是新颖性或投稿就绪认证。本次代码整理没有启动其中任何实验。

## 可检验的问题

主要问题：

> 在固定 T8 的 MCN 脉冲世界模型中，控制真实历史预热和模型容量后，放电后保留树突状态并使用输入依赖的遗忘门，是否改善基于想象的控制学习？

机制问题需要另行回答：提升是否与更好的历史信息利用有关，还是主要来自额外容量、状态初始化或优化变化？当前树突保留率日志不能直接证明“记忆更长”或“模型学会按需遗忘”。

## 优先补齐的实验

### 1. 先确认收益可复现

冻结当前实现与协议，至少使用 3 个独立训练种子，配对比较 Gated Memory、Stateful-T8 和完整 ANN-GRU。保留同一帧数下的全曲线、1M 终点和预先固定的末十点评估均值，不按每组最高点选结果。

seed 0 已参与设计迭代，应明确列为开发种子。新增种子不应用于反复选超参数；如果据此修改方法，需要披露选择过程并保留新的独立确认数据。十个评估回合不能替代独立训练种子。

### 2. 分开 burn-in、树突复位和门控

建议先在 Walker 上使用相同 B56/L64/T8、训练帧与更新预算：

| 对照 | 要回答的问题 | 当前证据缺口 |
|---|---|---|
| Stateful-T8，burn-in 0 vs 32 | 真实历史预热本身带来多少收益？ | context32 仅完成到 70K 检查点 |
| burn-in32 下，放电清空 vs 不清空树突 | 复位与持久保留的作用是否可分？ | 需构造并核对只改变该机制的对照，现有配置不提供任意混搭 |
| burn-in32 下，Static Slow Memory vs Gated Memory | 输入依赖门是否优于可训练但输入无关的保留率？ | Static 只完成到 90K 检查点 |
| 同容量控制 vs Gated Memory | 更多参数能否解释提升？ | 现有五组未配平，需单独设计有效容量控制 |
| 固定已训练模型，干预树突历史 | 控制表现是否依赖所保存的历史？ | 尚无记忆干预或专门记忆负载结果 |

Static Slow Memory 与 Gated Memory 的比较仍同时改变门投影参数量，不能把它直接称为严格参数匹配消融。参数控制应先约定保留哪些结构、宽度和计算预算，不能仅把一个大 baseline 随意加宽后归为“公平对照”。

放电不清空树突的单项对照也需明确其余泄漏/归一化/写入公式；当前 Slow Memory 还改变了保留更新，不能把二者差异全归给 reset。每次只实施必要变体，完整核对后再批准训练，不扩展成无边界的组合搜索。

### 3. 检查任务范围与机制

在 Walker 之外补充少量动力学和记忆要求不同的任务，再决定是否扩展。可先考虑 Cheetah Run 与 Cartpole Swingup Sparse，最终任务和预算应在运行前固定。若只补普通视觉控制任务，结论限于控制表现；要讨论长程记忆，还需明确的观测遮挡、延迟或其他历史负载，并区分新任务设计与原 DMC 协议。

树突状态清零、历史打乱等干预只能在独立评估分支实施，不污染原训练/评估状态，也不把干预后下降自动解释成唯一机制。结合预测误差、控制回报和门值分布解释结果；门值变化本身不足以建立因果关系。

## 统计与计算报告

训练种子是独立重复单位。先报告每个任务的配对种子差异与不确定性，再讨论跨任务聚合；样本不足时避免稳定性或统计功效的强结论。不能将回合或训练过程中的多个 checkpoint 当作额外独立重复。

当前最合适的论文方向是“脉冲世界模型中的状态与记忆管理”。效率不是现阶段已有结果：Gated Memory 的观测进程时长约 35.61 小时，ANN 约 11.21 小时，且没有统一负载的计算对照。若保留效率问题，应独立报告真实 policy、H15 imagination 和完整更新的 wall/CUDA 时间、显存与设备能耗；稠密 MAC、发放率代理和实测能耗必须分开。

下一轮若确认多种子收益，再投入完整机制消融与跨任务实验更合理。若收益明显缩小或静态保留已能解释大部分改善，应相应收窄方法与论文主张，保留负结果。无需现在承诺某个会议、性能门槛或能效收益。
